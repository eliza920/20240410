資料呈現與綁定 (Data Binding)

在這個範例中，我們學習如何使用 `{{ }}` 語法將 JavaScript 中的變數資料，綁定並顯示在 HTML 畫面上。

這就是 Vue 響應式系統的基礎！

事件處理 (methods)

使用 `v-on` 指令（或簡寫為 `@`）來監聽 DOM 事件，例如滑鼠點擊（@click）、鍵盤輸入（@keyup）等。

觸發事件後，會執行寫在 methods 裡面的 JavaScript 函數。

雙向綁定 (v-model)

主要用在表單元素（如 input, select, textarea）。

它能夠讓使用者在畫面上輸入的內容，即時同步更新到程式碼中的變數；反之亦然。

條件渲染 (v-if)

控制元素「要不要出現在畫面上」。

使用 `v-if`、`v-else-if`、`v-else` 來根據條件（true 或 false）決定是否渲染該區塊。

列表渲染 (v-for)

當我們有一個陣列 (Array) 資料時，可以使用 `v-for` 將陣列中的每一筆資料自動產生對應的 HTML 元素，非常適合用來製作清單或表格。

計算屬性 (computed)

如果一個資料需要經過複雜的計算才能顯示，我們就會用 computed。

它最大的優點是「具有快取特性」，只有當相依的原始資料改變時，它才會重新計算，能有效提升效能。

動態樣式與類別 (class & style)

使用 `v-bind:class` 或 `v-bind:style`，我們可以根據變數的狀態，動態地替換元素的 CSS 樣式。例如：任務完成時，字體自動變成灰色並加上刪除線。
